Computational Approaches to Q Source Analysis: A Methodological Framework with Calibration Transparency

Authors: LOGOS Research Collaborative

Date: January 2026

Status: Methodology Paper (Preliminary Results)

Keywords: Q Source, Synoptic Problem, Stylometry, Computational Text Analysis, Falsification Gates, Calibration

Abstract

This study presents a methodological framework for computational analysis of the hypothetical Q Source using meaning-anchored residual stylometry with rigorous falsification validation. We describe the implementation of five falsification gates and report transparent calibration results on a corpus of 38,746 style residuals and 2,378 translated passages. Our calibration achieves 47.5% accuracy in translator identification (2.4x above chance), with 4/5 falsification gates passing. Gate 2 (topic holdout generalization) fails, indicating the current methodology partially relies on topic features. We provide honest assessment of current capabilities and limitations, demonstrating that while stylometric signal is detectable, the system does not yet meet the 70% accuracy threshold required for high-confidence source reconstruction claims. This transparency enables the scholarly community to evaluate the methodology’s readiness for application to Q source analysis.

1. Introduction

1.1 The Synoptic Problem and the Q Hypothesis

The Synoptic Problem has occupied New Testament scholarship for over two centuries. The Two-Source Hypothesis posits that Matthew and Luke independently used Mark as a primary source, supplemented by a now-lost source designated “Q” (German Quelle) to explain their extensive agreements in non-Markan material (Streeter 1924; Kloppenborg 1987).

Q’s hypothetical status creates a methodological challenge: how can we study a document that exists only inferentially? This paper presents a computational framework designed to address this challenge while maintaining rigorous calibration transparency.

1.2 The Calibration Problem

Previous computational approaches to ancient source criticism have suffered from a lack of transparent calibration. Claims of high accuracy in source identification often lack:

  1. Baseline comparisons (chance performance)
  2. Falsification testing (can the system be fooled?)
  3. Generalization evidence (does it work on new data?)
  4. Honest error reporting (what doesn’t work?)

This study prioritizes calibration transparency over impressive-sounding claims.

2.2 Meaning-Anchored Residual Stylometry

2.2.1 Core Algorithm

For a text segment i in meaning cluster t:

Raw style: x_i
Cluster mean: μ_t
Cluster covariance: Σ_t
Residual: r_i = x_i - μ_t
Whitened residual: r'_i = Σ_t^(-1/2) · r_i

The whitened residual represents how a segment deviates from what its meaning context normally forces.

2.2.2 Feature Extraction

Function Words (Primary Features): - 50+ English function words for translation analysis - Frequencies normalized per 1,000 tokens - These features have been shown to be more robust to topic confounds

500-Word Chunks: - Texts segmented into non-overlapping 500-word chunks - Provides sufficient token count for reliable frequency estimation

2.3 Five Falsification Gates

We enforce five mandatory tests that any stylometric claim must pass:

Gate Test Purpose
1 Label Permutation Shuffled labels must collapse to chance
2 Topic Holdout Must generalize across meaning clusters
3 Confound Check Style must NOT predict topic
4 Random Features Random noise must achieve chance only
5 Stability Results must be consistent across folds

Gate 1 Analysis (PASS)

Gate 2 Analysis (FAIL)

  • Work holdout accuracy: 0.318
  • Topic holdout accuracy: 0.042
  • Ratio: 0.130 (required: 0.70)

  • Interpretation: Style features do not strongly predict topic

  • Random features: 0.250 (at chance)
  • Interpretation: Results are not achieved by random features

Gate 5 Analysis (PASS)

  • Fold standard deviation: 0.022
  • Interpretation: Results are stable across cross-validation folds

4. Discussion

4.1 What the Calibration Reveals

Positive Signals: 1. Function-word stylometry achieves 2.4x above chance accuracy 2. Certain translators (R.C. Seaton) are highly identifiable 3. 4/5 falsification gates pass 4. Results are stable and not due to random variation 5. Style features are not strongly confounded with topic

Current Limitations: 1. Overall accuracy (47.5%) does not meet 70% threshold 2. Gate 2 failure indicates topic dependence in generalization 3. Cross-translator confusion remains high 4. Synoptic gospel data not yet available for Mark benchmark

4.2 Implications for Q Reconstruction

The current calibration results indicate that the methodology is not yet ready for high-confidence Q reconstruction claims. Specifically:

  1. The 47.5% accuracy, while above chance, is insufficient for reliable source attribution
  2. Gate 2 failure suggests the model may attribute topic differences as source differences
  3. Without the Mark reconstruction benchmark, we cannot validate the approach on known ground truth

Responsible Scholarship Requires: - Waiting for improved calibration before making Q claims - Acquiring synoptic gospel data for proper benchmarking - Implementing meaning-anchored residualization to address Gate 2

4.3 Comparison to Prior Work

Unlike some computational biblical studies that report high accuracies without falsification testing, we provide:

5. Towards Valid Q Analysis

5.1 Required Improvements

Before Q reconstruction can be responsibly undertaken:

  1. Acquire synoptic data: Full Greek text of Matthew, Mark, Luke with verse alignments
  2. Mark reconstruction benchmark: Validate on known source before applying to Q
  3. Address Gate 2: Implement proper meaning-anchored residualization
  4. Achieve 70% accuracy: Pass Gate 1 threshold
  5. External validation: Test on known-authorship cases

5.2 Proposed Next Steps

  1. Data acquisition: Contact digital humanities projects for synoptic gospel data
  2. Methodology refinement: Implement shrinkage covariance estimation
  3. Expanded corpus: Include more distinct translators for better calibration
  4. Greek function words: Adapt English function word approach to Greek
  5. Parallel analysis: Use Gospel of Thomas as external witness

6. Conclusion

This study presents a computational framework for Q source analysis with unprecedented calibration transparency. We demonstrate that:

  1. Stylometric signal exists in translation data (2.4x above chance)
  2. Some authors/translators have distinctive signatures (R.C. Seaton: 76% F1)
  3. The methodology passes 4/5 falsification gates
  4. But current accuracy (47.5%) is insufficient for source reconstruction claims
  5. Topic holdout generalization fails, indicating methodology needs refinement

Rather than presenting unvalidated claims about Q, we provide an honest assessment of current capabilities and a roadmap for achieving the calibration threshold required for responsible scholarship.

The absence of confident claims is not a failure—it is intellectual honesty.
