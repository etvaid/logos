Conclusions

What Works

  1. Function-word stylometry shows real signal (2.4x above chance)
  2. Some translators are clearly identifiable (R.C. Seaton: 76% F1)
  3. 4/5 falsification gates pass
  4. Results are stable across folds (std 0.022)
  5. Style features don’t predict topic confounds (0.048 advantage)

What Needs Improvement

  1. Gate 1 accuracy needs to reach 0.70 (currently 0.475)
  2. Topic holdout generalization fails dramatically (0.13 ratio vs 0.70 required)
  3. Cross-translator confusion remains high for similar translation eras
  4. Synoptic gospel data needed for Mark reconstruction benchmark
  5. Gospel of Thomas needed for complete external source analysis

Honest Assessment

The current stylometry pipeline is scientifically defensible but not publication-ready for high-confidence claims. It demonstrates: - Real stylometric signal exists in translation data - Certain translators have distinctive signatures - The methodology passes most falsification checks

However, the failure of Gate 2 (topic holdout) indicates the model partly relies on topic/meaning features rather than pure style. This is a known challenge in stylometry.

Recommended Next Steps

  1. Acquire synoptic gospel data for Mark reconstruction benchmark
  2. Implement meaning-anchored residualization to address Gate 2 failure
  3. Expand translator corpus with more distinct translators
  4. Test on known-authorship cases before Q claims
  5. Apply shrinkage covariance estimation for whitening
